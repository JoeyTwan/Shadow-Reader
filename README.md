# Shadow Reader（影子读者）

> 不替你读书，陪你与作者对话。

Shadow Reader 让一本书"活"过来。上传一本书，你就拥有了和这本书的作者面对面交谈的机会——不是 AI 替你总结，而是作者本人，以他的口吻、他的立场，和你认真讨论书中的每一个观点。

---

## 它是什么样的体验

**你读《卓有成效的管理者》，彼得·德鲁克就坐在你对面。**

你认同他，他坦诚回应；你质疑他，他正面接招。他不讨好你，你也不需要认同他——求同存异，正是这场讨论的价值所在。

聊到一定深度，点一下「思想总结」，AI 会把你和作者讨论的结晶整理成一份属于你的思想记录：

- 你的核心观点是什么
- 你和作者在哪里分歧、在哪里共鸣
- 这场对话让你的想法发生了什么变化
- 还有哪些问题值得继续探索

---

## 怎么用

**三步，开始与作者对话：**

1. **上传** — 拖入一本 PDF 或 EPUB（最大 200MB，几乎覆盖所有电子书）
2. **对话** — 像和朋友聊天一样，向作者提问、反驳、请教。文字或语音都可以
3. **总结** — 随时点击「思想总结」，把讨论的成果沉淀下来

---

## 为什么值得用

**和作者本人对话，而不是和"AI"对话**
每一本书都对应一位作者。聊完这本书，换一本书，就是换一位作者——每场对话彼此独立，互不干扰。

**不讨好你的讨论**
它不迎合你的观点。你错了，它会指出；它错了，你也可以反驳。这是一场平等的思想交流，而不是一个只会说"你说得对"的聊天机器人。

**便宜的深聊**
它不需要把整本书塞给 AI——每次只检索与你话题相关的片段，加上最近的对话。一本书聊上 100 轮，成本不过一两块钱（DeepSeek）。

**语音也能聊**
不想打字？按住麦克风，直接说。桌面端 Chrome / Edge 和 Android 浏览器开箱即用。

**数据在你手里**
部署在你的服务器上，书籍、对话、思想记录全部存放在你自己的地盘，不经过第三方。

## 本地运行

```bash
# 1. 安装依赖
npm install

# 2. 配置 DeepSeek API Key
cp .env.example .env.local   # 填入 DEEPSEEK_API_KEY

# 3. 启动
npm run dev
```

打开 http://localhost:3000 即可开始。
